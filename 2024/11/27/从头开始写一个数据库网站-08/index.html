# 实现细节

  1. 列划分：
    • 使用 flex 布局， flex: 1 让每列平均分布。
    • 设置 min-width: 200px 确保在小屏幕时列不会太窄。
  2. 第一列：组织信息
    • 包括 Logo 图片、地址、版权声明。
    • Logo 样式通过 .footer-logo 控制。
  3. 其他列：关于、导航、联系
    • 每列用 h3 标题表示功能区名称。
    • 链接用 <ul><li><a></a></li></ul> 结构实现，易于扩展。
  4. 样式优化：
    • 在桌面端，列均分排列；在移动端，通过 @media 查询切换为垂直布局。
  5. 响应式设计：
    • 在小屏幕（宽度 <768px）下，列堆叠显示，保证可读性。
