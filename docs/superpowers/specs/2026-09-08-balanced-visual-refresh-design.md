# WhyLIM 个人主页平衡型视觉优化设计

## 目标

在不改变项目中心设计思想的前提下，提升字体、排版、色彩、动效、响应式和可访问性表现。

中心设计思想保持为：以地图连接访问者与主页所有者，通过阶段式地理叙事进入个人信息 Bento 页面。

设计参数：

- 设计变化度：6/10
- 动效强度：5/10
- 信息密度：4/10

## 保留范围

以下内容不改动：

- 地图作为全屏背景和叙事核心。
- “所有者位置、访问者位置、两者关系、探索详情”的阶段顺序。
- 最终状态的左右分屏布局。
- Bento 主层与第二层的信息分类。
- 个人资料、外部链接、路由、备案信息和站点域名。
- 浅色与深色主题、中英文切换、动画跳过和重播功能。

不引入新的组件库、状态管理方案、页面路由或内容模块。

## 设计语言

页面采用现代编辑感个人主页语言。地图提供空间叙事，衬线标题表达个性，克制的无衬线正文提供专业性。界面避免后台产品感和模板化三卡布局。

### 字体

- 英文展示字体：Newsreader，主要用于 Hero 标题、Bento 大标题和语录。
- 中文展示字体：Noto Serif SC，作为 Newsreader 的中文回退。
- 正文字体：Manrope，中文回退依次使用 Microsoft YaHei、PingFang SC 和系统无衬线字体。
- 数据字体：保留 JetBrains Mono，用于距离、时间百分比和语言缩写。
- Hero 标题使用紧凑字距与 `text-wrap: balance`，最大字号从 `text-9xl` 降至桌面约 `text-8xl`。
- 正文和语录使用 `text-wrap: pretty`，避免孤行和过宽文本。

字体继续通过当前 Google Fonts 方式加载，并保留 `display=swap`。不新增字体依赖包。

### 色彩

界面只使用一套金色强调系统：

- 浅色背景：`#F4F3EF`
- 深色背景：`#111410`
- 主金色：`#C6A15B`
- 深金色：`#8A682C`
- 浅色正文：`#1D2423`
- 深色正文：`#F2F0E9`

浅色模式的金色实心按钮使用深色文字，不再使用低对比白字。MBTI 的绿色标签以及 CV、博客、摄影卡片的蓝色、橙色、紫色交互色统一改为金色。照片和插画本身不受单一强调色约束。

### 表面与形状

- Hero 语录和 Bento 大卡片采用 24px 圆角。
- 普通卡片采用 20px 圆角。
- 标签采用 10px 圆角，主要操作和图标按钮使用全圆角。
- 浅色卡片使用较实的半透明暖白表面，深色卡片使用较实的炭黑表面。
- 模糊强度降低，阴影改为带背景色相的柔和阴影。
- 玻璃材质只用于真实的层级分离，不额外增加装饰卡片。

## 布局

### 应用外壳

- 根布局由 `h-screen` 改为 `min-h-[100dvh]`。
- 内容增加 `max-w-[1440px]` 居中约束，地图仍铺满视口。
- 顶部控制区保持右对齐，桌面高度不超过 64px。
- 页脚降低字号、对比和垂直占用，避免与 Bento 争夺视觉注意力。

### Hero

- 阶段 1 至阶段 3 继续居中显示。
- 阶段 4 使用约 42% 宽度，Bento 使用约 58% 宽度。
- Hero 内容宽度限制为约 520px。
- 标题、语录、距离和社交入口之间建立 24px、20px、16px 的递减节奏。
- 社交入口补充可访问名称和可见键盘焦点。

### Bento

- 桌面保留三列非对称网格，但 Bento 区域获得更多水平空间。
- 1280×720 下使用三行弹性卡片区域与一行紧凑翻页操作，目标是在单个右侧区域内完整显示。
- 桌面网格间距从 16px 调整为 12px，卡片内边距根据内容使用 18px 至 22px。
- 主层仍保留 MBTI、故乡、当前单位、技术栈、本科院校和 Coding Cat。
- 第二层仍保留日历进度、CV、博客和摄影。
- 翻页操作触发时，将 Bento 自身滚动容器复位到顶部。
- 移动端取消 Bento 内层滚动，使用页面的单一纵向滚动。

## 地图

- 将当前出现水印的瓦片地址替换为标准 OpenStreetMap 瓦片：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`。
- 恢复地图来源署名，并使用低对比小字号样式放置在底部角落。
- 浅色模式对瓦片使用低饱和、低对比滤镜。
- 深色模式对同一瓦片使用灰度、反相、亮度和对比滤镜，避免加载两套视觉不一致的资源。
- 地图标记、阶段聚焦和两点边界计算保持不变。
- 瓦片加载失败时，页面仍显示主题背景和已有文本内容，不增加随机占位地图。

## 动效

### 时间与节奏

- 阶段 1 停留约 2.2 秒。
- 阶段 2 停留约 1.8 秒。
- 首次访问约 4 秒进入总览。
- 地图飞行动画缩短到约 1.6 秒。
- 标题模糊切换缩短到 600 至 700ms。
- 展开 Bento 的水平位移从 100px 降至约 40px。
- 卡片入场移除缩放，改为 12px 纵向位移与 60ms 交错。
- 卡片悬停使用向上移动 2px、边框增强和轻微表面亮度变化。

所有动效必须服务于叙事阶段、层级进入、交互反馈或状态切换。

### 减少动效

检测 `prefers-reduced-motion: reduce` 后：

- 初始状态直接进入阶段 3。
- 地图切换不使用飞行动画。
- 标题不使用模糊和位移动画。
- Bento 卡片不交错进入。
- 技术栈停止跑马灯并允许横向静态浏览。
- 移除移动端循环箭头提示。

## 中英文与可访问性

- 为 Personality、Visit、Blog、View CV、Read、Gallery 和 Coding the World 等界面文字补齐翻译。
- 控制按钮继续使用 `aria-label`，并根据当前语言和状态提供准确文案。
- 社交图标链接增加可访问名称。
- 所有按钮和链接增加 `focus-visible` 焦点样式。
- 图标按钮的交互热区不小于 40px。
- 金色按钮文字对比度达到 WCAG AA。
- 图片继续保留描述性 `alt`，纯装饰图形使用空替代文本或隐藏于可访问树。

## 状态与依赖

- 地理位置不可用时继续显示“位置未知”，不阻塞主流程。
- 一言接口失败时继续使用现有本地备用语录。
- 外部图片失败时保留现有回退行为，但不新增第三方依赖。
- 主题、语言、阶段和动画跳过的现有数据流不改变。
- 仅增加减少动效判断和 Bento 滚动容器引用，不引入全局状态。

## 组件修改边界

- `App.tsx`：视口布局、阶段计时、主题覆盖层、分屏比例和减少动效入口。
- `Hero.tsx`：字体层级、间距、操作样式、社交可访问性和动效降级。
- `BentoGrid.tsx`：网格密度、统一强调色、滚动复位、翻译和动效降级。
- `MapBackground.tsx`：瓦片来源、滤镜类、署名和飞行动画时间。
- `ThemeToggle.tsx`、`LanguageToggle.tsx`、`AnimationControl.tsx`：统一控制样式、焦点状态和入场时间。
- `index.css`：字体、设计令牌、地图滤镜、表面样式、跑马灯和减少动效规则。
- `i18n.ts`：新增缺失翻译，不修改既有个人内容。

不进行无关重构，不拆分现有组件，不变更配置结构。

## 验证标准

### 静态验证

- `tsc --noEmit` 通过。
- `vite build` 通过。
- `git diff --check` 通过。
- 搜索确认界面代码中不存在旧的蓝色、橙色、紫色交互强调色。
- 搜索确认不存在 `h-screen` 和未降级的无限动画。

### 视觉验证

- 1280×720 浅色英文展开态完整显示核心 Bento，不出现页面、右栏和 Bento 三重滚动。
- 1280×720 深色英文展开态的 Hero、卡片标题、正文和操作清晰可读。
- 中文主层和第二层没有明显溢出、截断或中英文界面文案混用。
- 从 Bento 第二层返回主层后，内容从顶部正常显示，不出现大片空白。
- 地图不再出现 API KEY REQUIRED 水印，来源署名可见但不抢占注意力。
- 动画跳过、重播、主题切换和语言切换保持可用。
- 减少动效条件下没有地图飞行、循环跑马灯或重复提示动画。

## 完成定义

只有在静态验证全部通过，并完成浅色、深色、英文、中文和 Bento 翻页实测后，才能认为本次视觉优化完成。
